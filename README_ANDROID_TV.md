# لانشر Android TV — بناء APK عبر GitHub

هذا المستودع يحتوي على مشروع Expo/React Native ووحدة Kotlin محلية للـAndroid. يعرض التطبيق واجهة اللانشر المعتمدة نفسها داخل WebView أفقي، ويجلب قائمة التطبيقات القابلة للإطلاق من Android PackageManager عند التشغيل. يوفر GitHub Actions إعداد مشروع Android الناتج وبناء APK Debug قابل للتنزيل.

## البناء على GitHub من ملف ZIP

1. نزّل `tvlaunch-android-tv-source.zip` وفكّه. يحتوي الأرشيف على ملفات المشروع ومجلد `.github/workflows` المخفي.
2. أنشئ مستودعاً فارغاً على GitHub، ثم من Terminal داخل المجلد المستخرج نفّذ الأوامر التالية بعد استبدال `OWNER/REPOSITORY` بمسار مستودعك:

   ```bash
   git init -b main
   git add .
   git commit -m "Import Android TV launcher"
   git remote add origin https://github.com/OWNER/REPOSITORY.git
   git push -u origin main
   ```

3. يبدأ Workflow الموجود في `.github/workflows/build-android-tv.yml` عند push إلى `main` أو Pull Request، ويمكن تشغيله يدوياً من **Actions → Build Android TV Launcher → Run workflow**.
4. بعد نجاحه، افتح تشغيل Workflow ثم حمّل **android-tv-launcher-debug** من قسم Artifacts. يحتوي على `app-debug.apk`، وهو APK تجريبي موقّع بمفتاح Debug.
5. انقل APK إلى التلفاز وثبّته بعد السماح بالتثبيت من المصدر الذي استخدمته عند اللزوم. اضغط زر Home واختر اللانشر كواجهة افتراضية إذا أظهر Android شاشة الاختيار.

### متطلبات البناء

Workflow يضبط Node.js 22 وpnpm 9 وJava 17، ثم يثبت Platform Tools وAndroid API 36 وBuild Tools 36.0.0 وNDK 27.1.12297006 وCMake 3.22.1 اللازمة للبناء. أقل إصدار مستهدف للتثبيت Android 9 (API 28)، ويُجهّز التطبيق للتشغيل على Android TV بإصداراته الأحدث. لا يلزم EAS token أو متغيرات سرية لهذا المسار. لم أرفق APK مسبقاً؛ يجب أن ينجح تشغيل GitHub Actions في مستودعك أولاً.

للبناء اليدوي بعد إعداد الأدوات نفسها:

```bash
pnpm install --frozen-lockfile
pnpm android:prebuild
cd android
./gradlew --no-daemon :app:assembleDebug
```

ينتج الملف في `android/app/build/outputs/apk/debug/app-debug.apk`.

## ما يفعله التطبيق الأصلي

- واجهة 16:9 أفقية قابلة للتنقل بالريموت والأسهم وEnter وBack، ومكتبة تُحمّل التطبيقات المثبتة ذات أنشطة التشغيل من Android. يحاول YouTube وGoogle Play الفتح عبر الحزم الأصلية الخاصة بهما.
- الطقس الحي وتوقع الأيام السبعة عبر Open-Meteo، ومواقيت الصلاة المحلية كما في المعاينة، مع اختيار المدينة وطريقة الحساب. تصل تذكيرات الصلاة عبر Android Notifications بعد موافقة المستخدم. يعيد Expo Notifications تسجيل المواعيد المحفوظة بعد الإقلاع؛ وتُجدول المواعيد المقبلة ضمن البيانات التي يجلبها التطبيق، لذا افتح اللانشر دورياً كي يحدّث الأيام اللاحقة. على Android 12+ يستخدم Expo تنبيهاً غير دقيق إذا لم تسمح إعدادات النظام بالتنبيهات الدقيقة، وقد تؤخر سياسات توفير الطاقة وصوله.
- اختبار السرعة تقديري من التطبيق إلى Cloudflare، وليس قراءة خاصة بمحول Wi‑Fi. تعرض بطاقة الذاكرة إجمالي/متاح RAM ويفتح زر المسح إعدادات إدارة التطبيقات بدلاً من إيقاف عمليات تطبيقات أخرى.
- تتضمن القناة نغمة تنبيه هادئة. يمكن اختيار ملف صوتي محلي وتشغيله داخل الواجهة المفتوحة، لكن Android يجعل صوت قناة الإشعار إعداداً نظامياً ثابتاً؛ لذلك يستخدم إشعار الخلفية النغمة المضمّنة أو صوت النظام، وليس ملفاً محلياً تختاره ديناميكياً.

## حدود Android

يضيف التطبيق نفسه كمرشح HOME وLeanback، لكن Android يظل صاحب قرار اختيار اللانشر الافتراضي. Android 10 وما بعده لا يسمح عادة للتطبيقات العادية بتمكين/تعطيل Wi‑Fi برمجياً، وAndroid 13 وما بعده يقيّد تغيير Bluetooth؛ لذلك تفتح الأزرار صفحات إعدادات النظام. لا يستطيع التطبيق العادي قتل عمليات تطبيقات أخرى لمسح RAM أو إطفاء التلفاز/قطع الطاقة؛ يعرض الذاكرة ويفتح إعداداتها، وخيار الخمول يعتّم واجهة اللانشر فقط. يتطلب التحكم الأعمق تطبيقاً نظامياً أو Device Owner أو دعماً من الشركة المصنّعة.

هذا APK للتجربة، وليس إصداراً للنشر في متجر Google Play. كل تشغيل GitHub Actions ينشئ توقيع Debug جديداً؛ إذا رفض Android تحديث نسخة سابقة، أزلها قبل تثبيت الجديدة. يتطلب إصدار إنتاج قابل للتحديث إعداد مفتاح توقيع Release وحفظه سراً في GitHub Secrets.

## إصلاح إعداد Android SDK وتنظيف المصدر

يوقف Workflow قبول كل تراخيص Android SDK دفعة واحدة. يثبت فقط الحزم المحددة أعلاه، ويتجنب إضافة تراخيص Google TV وAndroid XR. إذا كان تثبيت إحدى الحزم المطلوبة يحتاج موافقة SDK، يرسل الأمر قبولاً أثناء تثبيت تلك الحزم المحددة فقط. عند فشل `sdkmanager` تتوقف المهمة برمز الخروج الحقيقي، ويظهر سبب التثبيت في سجل GitHub Actions.

اختُصر مسار التطبيق إلى شاشة واحدة مع WebView، وحُذفت شاشات ومكوّنات Expo التجريبية غير المستعملة وملفات الصور الموروثة من قالب React وطبقة NativeWind. احتُفظ بملفات معاينة الويب، وKotlin Native Module وConfig Plugin وأصول التطبيق. كما بقي خادم المشروع وقاعدة بياناته لأن إعداد WebDev الحالي ما زال يعرّف نقطة API على المنفذ 3000.
